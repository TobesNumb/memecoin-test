# assets/

- `logo.png`: placeholder-logo (512×512 PNG). Vervang dit in fase 2 door het echte logo.
  pump.fun accepteert PNG, JPG, GIF en WEBP; een vierkant beeld van minimaal 512×512 is gebruikelijk.
- Het pad naar het logo staat in `token.config.ts` (`logoPath`).
- De landingspagina in `web/` serveert deze map als `/` (bijv. `/logo.png`).
